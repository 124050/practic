# Матрица приоритизации бизнес-процессов

Приложение для анализа и визуализации бизнес-процессов на основе операционной эффективности и стратегической значимости.

## Основной функционал
* **Добавление процессов:** ввод данных по 8 критериям.
* **Автоматический расчет:** вычисление средних баллов и определение одной из 4-х зон.
* **Интерактивная матрица:** визуальное распределение процессов по квадрантам.
* **Фильтрация и сортировка:** удобный поиск и упорядочивание данных в таблице.
* **Хранение данных:** автоматическое сохранение в `localStorage` (данные не пропадают при перезагрузке).
* **Экспорт:** выгрузка текущего списка процессов в файл `priority-matrix.json`.
* **Сброс:** возможность вернуть демонстрационные данные в один клик.

## Как запустить
1. Склонируйте репозиторий или скачайте архив.
2. Откройте файл `index.html` в любом современном браузере.
